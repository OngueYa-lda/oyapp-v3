## Paginas

- Copia a pagina 'hoteis' encontrada na pasta 'pages'
- Edita o titulo da pagina
- Edita o nome da funcao da pagina
- apaga o codigo antigo, de acordo do que precisa de ser apagado
- adiciona novas tags, seguindo o formato das paginas existentes
- O CSS de paginas esta dentro da pasta 'styles', chamado Page.module.css
- O codigo usa 'CSS modules', [leia](https://github.com/css-modules/css-modules)
- Siga o formato dos nomes das classes e JSX
- Para tags 'img' usa 'Image'
- Para tags 'a' usa 'Link' com href e 'a' dentro da tag Link, ha exemplos no codigo

## Algumas dicas e instruções GIT

- Utilizamos o Bitbucket como repositório
- Onde temos duas branch: `develop` & `main`
- `Develop` é para desenvolvimento
- `Main` é para produção
- Faça o clone do repositório para a sua máquina local
- Faça o `npm install`, e não corra elo várias vezes, é longo e pode alterar o ficheiro `package-lock.json` que vai afetar outros desenvolvedor na equipa.
- Trabalhe localmente na branch `develop` e faça os pushs mesmo nesta branch
- Caso tenhas terminado o teu trabalho, precisa primeiro ser revisado
- Depois de revisado e correcto o teu código pode ser enviado para a branch `main` 
- A actualização da app online é feita automaticamente.
- Num novo dia de trabalho, antes de começar, faça um `git pull` para garantir que tens o codigo mais recente na tua máquina.
- Verifica que o `npm test` corre sem erros, se este for caso tudo está certo com o mundo.
- Para publicar código num branch faça `git push`. `git merge` é dedicado à casos especias. Confira com à equipa.
- Antes de publicar o teu código, faça de novo um `git pull` só para verificar que não há conflictos com outro código já no repositório.
- Se encontrares um conflicto com o git, notifica a equipa

## Comandos do projecto

- `npm run dev` inicia o servidor em modo de auto-compilação
- `npm start` inicia o servidor direitamente
- `npm test` corre testes
- `npm run lint` valida a sintaxe e boas práticas no codigo
(Leia o guião para as melhores práticas)
- `npm run build` compila o projecto
